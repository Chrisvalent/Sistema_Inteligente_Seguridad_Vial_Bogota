# Diagnóstico preventivo intersección × fecha × hora

Estado aceptado: no entrenar ni validar un predictor de ocurrencia con la cobertura espacial actual y sin negativos confirmados.

Los CSV corresponden al panel teórico de 50 ubicaciones candidatas. “Sin reporte registrado” no equivale a negativo verdadero. Las 50 ubicaciones siguen sin validación humana: 43 ambiguas y 7 únicas pendientes.

Fuentes reproducibles: `src/Dataset4/diagnostico_panel_interseccion_hora.py`; `models/diagnostico_panel_interseccion_hora.json`.
